What is mining?

Each computer races to solve a hard math puzzle. The winner gets to add the next block to the chain and earns 50 coins as a reward.

What is an orphaned block?

When two computers finish mining at nearly the same time, only one can win. The other's block is discarded (orphaned) — its work is wasted.

What is a spoof / double-spend?

A cheat attempt: spending the same coins twice, or faking a transaction. The network automatically detects and rejects these every time.

Why is it secure?

Every block contains a fingerprint (hash) of the block before it. Changing any block would break every block after it — and every other computer would instantly reject the tampered chain.
